# Customer Churn Prediction

## Project Overview
This is a Machine Learning Capstone Project that predicts whether a telecom customer is likely to leave the service (Customer Churn).

The project uses Logistic Regression and Random Forest algorithms.

## Project Objectives
- Analyze customer churn data.
- Perform data preprocessing and cleaning.
- Train Machine Learning models.
- Predict customer churn.
- Build an interactive Streamlit application.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib
- Streamlit
- Jupyter Notebook

## Project Structure

- `Customer_Churn_Prediction.ipynb` – Jupyter Notebook
- `app.py` – Streamlit Web Application
- `requirements.txt` – Required Python Libraries
- `models/churn_model.pkl` – Saved Machine Learning Model
- `WA_Fn-UseC_-Telco-Customer-Churn.csv` – Dataset
- `Customer_Churn_Prediction_Final_Report.pdf` – Project Report
- `Customer_Churn_Prediction_Presentation.pptx` – Project Presentation

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```

## Machine Learning Models
- Logistic Regression
- Random Forest

## Output
The application displays:
- Customer churn prediction
- Estimated churn probability
- Customer retention result

## Conclusion
This project demonstrates how Machine Learning can help telecom companies identify customers who may leave their services and improve customer retention.
